# Changelog

## 0.1.0 — development preview

Original ry interface, Codex and Claude connectors, named homes, separate quota buckets, remaining/used meters, menu-bar pinning, cache freshness, local rule-based advice, demo mode, login-item settings, tests and macOS packaging scripts. Public signing, notarisation and real-account acceptance remain pending. Grok and Kimi support is planned.

## 0.1.1 — development preview

Removed the top header and moved refresh to the bottom controls. Compacted account cards so the two-provider demo fits without scrolling. Added provider browser sign-in with a separate native progress window, Codex login isolation, optional Claude code entry, cancellation and timeout handling. Added five simulated portal lifecycle checks. Live account acceptance remains pending.

## 0.1.2 — development preview

Fixed Claude Desktop helper discovery, preferring the newest native helper version. Claude sign-in now explicitly opens the provider portal from the app and requests subscription authentication. Added discovery regression coverage.

## 0.1.3 — development preview

Smaller 340-point panel, tighter cards and bottom controls. Replaced the opaque panel background with native macOS popover material, translucent card surfaces and semantic secondary text. macOS manages material appearance and Reduce Transparency behaviour.
